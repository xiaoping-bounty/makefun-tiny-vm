# makefun-tiny-vm

A tiny stack VM for make.fun's "Build a tiny stack virtual machine" bounty, implementing the ISA's reference semantics exactly — every trap code, bound and wrapping rule included.

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```

Entered on [make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
